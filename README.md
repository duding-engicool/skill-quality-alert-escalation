# 质量预警升级助手（quality-alert-escalation）

面向 **质量经理 / 现场主管** 的技能：规范质量异常预警的分级、升级矩阵与响应时限，自动生成升级流程与实时看板，输出 **纯文字版(.txt) + Markdown(.md)**。

## 适用角色

- 质量经理
- 现场主管 / 线长

## 使用方式

```bash
# 使用内置小样本（首次跑通验证）
python scripts/build_report.py --out-dir ./out

# 使用自有数据
python scripts/build_report.py --input events.json --out-dir ./out
```

## 输入字段（摘要）

- `meta`：工厂、班次、日期、负责人。
- `events[]`：事件编号、产线、工位、缺陷、等级(L1–L4)、检出/涉及数量、发生时间、响应时间、响应人。

## 升级矩阵（通用参考，企业可覆盖）

| 等级 | 触发 | 通知对象 | 响应时限 | 标准动作 |
|------|------|----------|----------|----------|
| L1 轻微 | 单件/局部 | 班组长 | ≤4h | 现场纠正+记录 |
| L2 一般 | 小批量 | 线长→主管 | ≤2h | 遏制+初步分析 |
| L3 严重 | 影响整线/客户风险 | 主管→质量经理 | ≤1h | 隔离+启动 8D |
| L4 重大 | 安全/法规/批量流出 | 经理→总监/客户 | ≤30min | 全线停+上报 |

## 防幻觉声明

组织层级、人员职责、时限阈值缺失时标「待企业补充」；分级默认参考通用矩阵，非强制标准，最终以企业制度为准。
